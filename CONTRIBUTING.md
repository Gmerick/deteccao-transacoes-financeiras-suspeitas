# Como contribuir

1. Crie uma branch a partir de `main`.
2. Faça mudanças pequenas e documentadas.
3. Execute `python run_pipeline.py` e os testes.
4. Não inclua dados pessoais, credenciais ou transações reais.
5. Abra um pull request explicando o problema, a solução e a validação.

Contribuições úteis incluem novas regras, testes temporais, medidas DAX, consultas SQL, acessibilidade do dashboard e comparação com modelos de anomalia.
